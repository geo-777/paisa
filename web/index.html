Built for reality, not marketing

Most personal finance apps want your SMS inbox and your credit score. Paisa only asks what you spent.

Typical Finance Apps
  • Demands SMS permissions to harvest financial transaction messages.
  • Constant upsells for credit cards, personal loans, and insurance products.
  • Bloated onboarding with mandatory income setups and rigid budget seminars.
  • Fails on poor Wi-Fi when waiting at canteen or tea stall counters.
  • Proprietary lock-in where exporting your own records is behind a paywall.
Paisa
  • Zero SMS access. You type the amount in three taps. Complete privacy.
  • No ads or telemetry. 100% distraction-free student finance tool.
  • Time-based auto categories. Automatically guesses Breakfast, Lunch, Snacks, or Dinner.
  • Local-first offline engine. Queues writes instantly and syncs quietly on reconnect.
  • Open source & Sheets mirror. You own your database, with optional Google Sheets backup.
Core Features

Everything essential. Nothing extra.

Focused features designed strictly around how college students actually spend.

01 / SPEED
Sub-Second Logging

Automatic category heuristics default to Breakfast before 11:00, Lunch between 11:00–16:00, Snacks until 19:00, and Dinner after 19:00. No endless dropdown menus.

02 / RESILIENCE
Local-First Offline Cache

Works seamlessly in campus basements or spotty hostel Wi-Fi. Expenses are written instantly to AsyncStorage and reconciled with Supabase once network connectivity returns.

03 / OWNERSHIP
Google Sheets Mirror

Optionally pipe every logged expense directly into your personal Google Sheet via a lightweight Apps Script endpoint. Zero Drive permission needed.

04 / INSIGHTS
Calm Analytics

Answers two essential questions: where did your money go, and are you spending higher than usual? Subtle amber caution indicators trigger only if today spikes above 1.5× baseline.

05 / PRIVACY
Postgres Row-Level Security

Every database row is secured at the database kernel level with auth.uid() checks. Even backend database queries can only view records belonging to the authenticated student.

06 / FREEDOM
Permissive MIT License

Transparent, audit-friendly codebase. Run it with the hosted backend or self-host your own Supabase instance using the included schema.sql migration.

Technical Architecture

Designed for speed and strict correctness

Expo SDK 57 React Native TypeScript Strict Supabase Postgres Zustand

Every single calculation rule (month total, days elapsed, baseline comparisons, caution triggers, category share largest-remainder algorithms) lives in isolated pure functions tested by unit suites. No math is calculated inside UI components.

STEP 01
Fast UI Input
Optimistic modal generates a local UUID and updates UI in zero milliseconds.
STEP 02
Durable Storage
Entry is immediately committed to device storage in pending state.
STEP 03
Supabase Upsert
Sync worker uploads entry with RLS check, marking status synced upon receipt.
STEP 04
Optional Mirror
Async webhook appends row to personal Google Sheet without blocking the user.
